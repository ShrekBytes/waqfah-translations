# waqfah-translations

Quran translation databases (.db / SQLite) downloaded at runtime by the
[Waqfah](https://github.com/ShrekBytes/waqfah) Android app. Integrity is
guaranteed by SHA-256 checksums pinned inside the app, independent of this host.

## Where this content comes from

**We do not own these works and claim no rights over them.** All Quran text,
translations and related data hosted here were obtained from public community
projects — primarily:

- [Tanzil Project](https://tanzil.net) — Quran text (CC BY 3.0) and many
  translations (see per-directory TANZIL.md notices)
- [Quranic Universal Library (QUL)](https://qul.tarteel.ai/resources) —
  translations, scripts and fonts

All rights belong to their respective publishers, translators and authors.
These files are hosted here solely so Waqfah can serve its downloads, and any
use of this content is subject to the respective platforms' and publishers'
terms of use.
